# 25EDC - 2025年电赛G题：电路模型探究装置  (国二作品)


> **"软硬结合，以算代测"** —— 基于 STM32F407 的电路模型黑盒探究装置

![](https://cdn.jsdelivr.net/gh/dixiLOG/blogStatic/image-20251215130949810.png)

## 项目简介

本项目为 **2025年全国大学生电子设计竞赛 G题（电路模型探究装置）** 的参赛源码

装置能够对“已知模型电路”进行精确输出控制，并可对由 RLC 元件组成的“未知模型电路”（二阶低通、高通、带通、带阻）进行**自主扫频学习**、**类型识别**、**参数建模**，并最终在单片机内部推导差分方程，实现**模拟滤波复现**


**核心指标：**

- **已知电路控制**：输出电压相对误差绝对值 ≤ 2.0%
- **未知电路学习**：类型判断成功率 100%
- **模拟复现精度**：与真实电路输出峰峰值相对误差 ≤ 12%
- **建模时间**：\< 2分钟（实际约几十秒）

-----

##  硬件架构

- **MCU**: STM32F407VG (1MB Flash, 192KB SRAM)
- **信号发生**:
  - **DDS**: AD9833 (产生正弦波频率) 
  - **VCA**: AD603 + DAC7612 (程控增益，实现稳幅和目标电压输出) 
- **信号采集**:
  - **ADC**: STM32内置 ADC1 (有效值检测) & ADC3 (实时滤波输入) 
  - **RMS检测**: **AD637** 真有效值转换芯片 (高精度AC-DC)
- **交互**: FSMC驱动 LCD电阻触摸屏

## 核心算法与实现原理

本项目放弃了计算量大且易受干扰的FFT方案，转而采用**最小二乘法 (LSF) 拟合**与**特征值分析法**相结合的策略

### 1. 信号发生与扫频 (`learning_mode.c`)

  - 采用 **对数扫频** 策略（500Hz - 250kHz），保证在低频和高频段都有足够的特征点
  - 通过 `DAC7612` 动态调整 `AD603` 的增益电压，补偿不同频率下的硬件衰减，确保扫频信号源的平坦度

### 2. 滤波器类型辨识 (`filter_analyzer.c`)

- **峰谷搜索**：在扫频得到的幅频响应数组中搜索最大值 $V_{max}$ 和最小值 $V_{min}$
- **阈值判决**：设定 $V_{th} = V_{max} / \sqrt{2}$ (-3dB点)
- **逻辑分支**：
  - 起始与截止频率增益均低 -\> **带通**
  - 起始与截止频率增益均高 -\> **带阻**
  - 起始高，截止低 -\> **低通**
  - 起始低，截止高 -\> **高通**

### 3. 系统建模 (`filter_analyzer.c`)

解决了传统方法难以精确计算 Q 值的问题

#### A. 低通/高通建模：线性化最小二乘法 (LSF)

对于二阶低通滤波器，其传递函数模的平方倒数与频率平方呈现线性关系。我们将非线性曲线转化为线性方程 $Y = C_1 X_1 + C_2 X_2$ 进行拟合：

$$
\frac{1}{|H(j\omega)|^2} - 1 = (\frac{1}{Q^2}-2)\frac{\omega^2}{\omega_0^2} + \frac{\omega^4}{\omega_0^4}
$$

代码实现中（`Calculate_Filter_Params`）：

1.  **数据筛选**：剔除底噪区域和通带平坦区域，只保留过渡带数据  
2.  **正则化归一化**：为了防止 float 精度溢出，对频率 $\omega$ 进行归一化处理  
3.  **矩阵求解**：构建正规方程组，求解 $C_1, C_2$，反解出 $\omega_0$ (截止频率) 和 $Q$ (品质因数)。

#### B. 带通/带阻建模：特征点几何分析 [cite: 52-58]

- **带通**：搜索峰值两侧的 -3dB 频率点 ($f_L, f_H$)，计算 $BW = f_H - f_L$, $Q = f_0 / BW$
- **带阻**：利用通带平均增益作为基准，反向搜索下陷处的 -3dB 点
- **插值优化**：在离散的扫频点之间使用**线性插值**，精确锁定 -3dB 频率，将频率误差控制在 1% 以内

### 4. 模拟复现 (`main.c` - `ADC_IRQHandler`)

建模完成后，计算出数字 IIR 滤波器的系数 ($b_0, b_1, b_2, a_1, a_2$)。在 ADC 中断中运行差分方程：

```c
// 实时 IIR 滤波核心代码
float y_n = g_iir_coeffs.b[0] * x_n + g_iir_coeffs.b[1] * x_prev1 + g_iir_coeffs.b[2] * x_prev2
          - g_iir_coeffs.a[1] * y_prev1 - g_iir_coeffs.a[2] * y_prev2;
```

利用 STM32 的 FPU 单元，实现了极低延迟的实时信号跟随

## UI 交互设计系统

为了在有限的屏幕空间内实现复杂的参数配置和波形展示，本项目在 `touch.c` 中实现了一套轻量级的 **GUI 框架**

### 1. 界面布局策略

- **分栏设计**：
  - **右侧参数栏** (`ui_draw_param_list`)：常驻显示关键参数（频率、幅值、补偿偏置等），点击即可选中
  - **左侧主控区**：根据状态动态切换内容
    - **设置模式**：显示虚拟数字小键盘 (`ui_draw_numpad`)，支持浮点数输入
    - **绘图模式**：显示幅频响应曲线 (`draw_learning_results`) 或 实时波形
  - **底部状态栏** (`ui_draw_status_bar`)：实时显示系统状态（设置中、扫频中、模拟中）

### 2. 状态机管理 (`touch.c` / `learning_mode.c`)

系统采用有限状态机 (FSM) 管理 UI 逻辑，确保操作互斥且流畅：

| 状态枚举 | 描述 | 触发条件 |
| :--- | :--- | :--- |
| `STATE_PARAM_SETTINGS` | **参数设置**：主界面，配置扫频范围、目标电压。 | 上电默认 / 按下 HOME 键 |
| `STATE_DDS_OUTPUT` | **信号发生**：控制 AD9833 输出指定频率波形。 | 按下 KEY4 |
| `STATE_LEARNING_START` | **开始学习**：触发自动扫频与建模流程 (阻塞式)。 | 按下 KEY3 (学习键) |
| `STATE_LEARNING_DONE` | **结果展示**：绘制幅频曲线，显示辨识出的滤波器类型与参数。 | 学习流程结束自动跳转 |
| `STATE_SIMULATION` | **模拟复现**：运行数字滤波器，实时处理输入信号。 | 按下 KEY2 |

### 3\. 可视化反馈

- **实时扫频进度**：在 `STATE_LEARNING_START` 状态下，屏幕动态绘制扫频进度条
- **对数坐标绘图**：在结果展示页，采用对数 X 轴绘制幅频特性曲线，直观呈现滤波器的截止频率与带宽特性

### 方案选型

在比赛初期，我们面临着**FFT**与**LSF拟合**的抉择。

  * **FFT方案**：虽然直观，但 STM32F4 在有限时间内很难对全频段进行高分辨率的 FFT，且对于非测试频率的噪声非常敏感，容易导致模型参数跑偏
  * **LSF方案**：我们最终选择了基于模型的系统辨识。通过推导二阶系统的传递函数，将其转化为线性回归问题。事实证明，这种方法**鲁棒性极强**，利用了整个过渡带的数据，天然平滑了噪声，使得我们在测量误差存在的情况下，依然能精准反推出电路参数

### 遇到的坑

  * **AD603 的非线性**：理论上 AD603 是 dB 线性的，但在实际调试中发现其增益曲线与控制电压并非完美线性。我们不得不通过 `learning_mode.c` 中的查表和反馈校准（Look-up Table）来补偿这一误差，确保扫频信号的幅度恒定
  * **程控放大自激**：输出对地接一个3.3nF电容，规避跟随运放寄生参数
  * **RAM 危机**：虽然 F407 有 192KB RAM，但同时开启大数组存储扫频数据、运行 DSP 库运算、以及 LCD 显存缓冲，险些爆栈。最终通过复用缓冲区和精简数据结构（`FreqResponsePoint`）解决了问题
